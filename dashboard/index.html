How NHI Communicator works · Skinwalker Ranch context

The inspiration: HISTORY's The Secret of Skinwalker Ranch features radio-frequency experiments. This app uses 1600 MHz as a starting receive frequency and laboratory preset. The show provides context for an experiment, not verification of a signal's origin. The app is independently developed and is not affiliated with HISTORY or the show.

  1. Listen and visualize. HackRF One captures actual complex I/Q samples at 8 million samples per second. An 8,192-bin FFT produces a spectrum and waterfall with approximately 977 Hz bin spacing across 8 MHz. Colors show relative power; new receive rows appear at the top.
  2. Inspect the primes. Offline preview builds an unencrypted ASCII packet containing a sequence number and prime numbers, with CRC32 checks for accidental corruption. Prime numbers provide a recognizable mathematical test pattern. Preview uses no radio transmission.
  3. Run a contained lab test. With the explicit shielded-lab launch and setup confirmation, the app converts a packet into 8 kbaud binary FSK, sends it through the shielded, attenuated conducted setup, then listens for four seconds. HackRF One is half duplex, so it cannot receive while transmitting.
  4. Check matching frames. The response monitor displays only packets that match this app's modem and pass its CRC checks. It is not a decoder for arbitrary signals. Received energy or a valid packet does not identify its sender, prove NHI contact, or guarantee a reply.

Reading the waterfall: Horizontal position is frequency and vertical position is time. Narrow persistent signals appear as vertical lines; short bursts appear as horizontal traces. Gray lines mark receive gaps. Zoom changes the displayed span, not the radio or FFT resolution. With no receiver attached, the spectrum stays empty and offline packet preview remains available.
